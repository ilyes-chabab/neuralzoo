## Veille mlp (multi layer perceptron) 

### définition :

feed forward : 
Un modèle en feed forward est un modèle où la donnée va faire de l'entréé vers la sortie

backpropagation : 
C'est un algorithme qui permet au réseau de neuronne d'apprendre de ses erreurs , pour se faire il faut comparer le résultat aléatoire du réseau a la cible réelle puis appliquer une fonciton de cout (loss function)
